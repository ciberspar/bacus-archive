# Bacus-Archive

### Your files. Your space. Your archive.
### Tus archivos. Tu espacio. Tu archivo.

A clean, accessible and responsive file-management interface,
designed to evolve into a cloud storage platform for everyone.

Una interfaz limpia, accesible y adaptable para gestionar archivos,
diseñada para evolucionar hacia una nube para todas las personas.

**Status / Estado:** Early development / Desarrollo inicial

</div>

---

## 🌿 About / Acerca del proyecto

**English**

Bacus-Archive is an open development project exploring a simple,
user-friendly way to organize digital files.

The goal is to build a platform that works across devices, is easy
to understand, and can eventually provide secure, persistent cloud
storage for multiple users.

**Español**

Bacus-Archive es un proyecto en desarrollo que busca ofrecer una
forma sencilla y accesible de organizar archivos digitales.

El objetivo es construir una plataforma compatible con distintos
dispositivos, fácil de entender y que pueda ofrecer almacenamiento
en la nube persistente para múltiples usuarios.

## ✨ Current features / Funciones actuales

- [x] Responsive interface for desktop and mobile.
- [x] Responsive interface for phones and computers.
- [x] Local file selection through the browser.
- [x] Selección local de archivos desde el navegador.
- [x] Image previews for selected local images.
- [x] Vistas previas de imágenes seleccionadas.
- [x] Search by filename.
- [x] Búsqueda por nombre de archivo.
- [x] File categories and navigation.
- [x] Categorías de archivos y navegación.
- [x] Session-only favorites and trash list.
- [x] Favoritos y papelera temporales durante la sesión.

These features run in the browser. They do not upload files to a
server or provide persistent cloud storage.

Estas funciones se ejecutan en el navegador. No suben archivos a un
servidor ni ofrecen almacenamiento persistente en la nube.

## 🚀 Getting started / Primeros pasos

### Option 1: GitHub Pages

Once GitHub Pages is enabled for this repository, open the published
site in your browser.

Una vez activado GitHub Pages para este repositorio, abrí el sitio
publicado en el navegador.

GitHub Pages can host the static interface, but it does not provide
the backend or persistent private file storage needed for a real
cloud service.

GitHub Pages puede alojar la interfaz estática, pero no proporciona
el servidor ni el almacenamiento privado persistente necesarios
para una nube real.

### Option 2: Run locally / Ejecutar localmente

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Select local files to explore the interface.

1. Descargá o cloná este repositorio.
2. Abrí `index.html` en un navegador moderno.
3. Seleccioná archivos locales para explorar la interfaz.

No installation is required for this basic demonstration.

No hace falta instalar programas para esta demostración básica.

## 🔐 Security and privacy / Seguridad y privacidad

Bacus-Archive is currently a frontend demonstration.

It does not currently provide:

- Real user accounts or authentication.
- Server-side file storage.
- Cloud synchronization.
- Production-grade access controls.
- A security-reviewed backend.

Bacus-Archive es actualmente una demostración de frontend.

Todavía no ofrece:

- Cuentas de usuario ni autenticación reales.
- Almacenamiento de archivos en un servidor.
- Sincronización en la nube.
- Controles de acceso de producción.
- Un backend revisado desde el punto de vista de seguridad.

Do not treat this prototype as a secure cloud storage service.
Do not upload sensitive files to an untrusted deployment.

No consideres este prototipo un servicio seguro de almacenamiento
en la nube. No subas archivos sensibles a una publicación no confiable.

See [SECURITY.md](SECURITY.md) for security reporting information,
if that file has been added.

Consultá [SECURITY.md](SECURITY.md) para información sobre cómo
informar problemas de seguridad, si ese archivo ya fue creado.
